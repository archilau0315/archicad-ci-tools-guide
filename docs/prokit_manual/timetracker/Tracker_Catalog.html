Library Objects for Project Tracking

The ProKit Time Tracker libpack contains useful objects related to project tracking, such as Gantt charts and a Transmittal Form.

To place the Transmittal Form (containing data from closed Transmittal Sets), use the command at ProKit > Time Tracker > Place or Update Document Transmittal Form.
