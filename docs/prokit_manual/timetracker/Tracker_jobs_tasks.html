Manage Jobs and Tasks

Use ProKit > Time Tracker to open the "Manage Jobs" and "Manage Tasks" dialogs.

The Manage Jobs and Manage Tasks dialogs contain the list of the project's existing Jobs and Tasks. Use the dialogs to add, delete, import and export this data.

These job and task files use the .jobs and .tasksextensions.
