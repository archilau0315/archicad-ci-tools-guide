Using the ProKit Transformer functions

Note: These commands are not undoable.

Mirror, move or rotate project

  1. Select the desired command from the ProKit > Transformer menu:
  2. In the Archicad view, click the start point.
    • To mirror the project: At the first click, the tool displays a guide to the mirror action, which can only be across a horizontal or vertical line. The image will dynamically switch between the horizontal and vertical axis depending on which is closer to your mouse. When the axis is in the desired direction, click to mirror the project.
    • To move or rotate the project: Click in the view, then use the appearing guide to set the move distance or rotation angle. Click again to carry out the transformation.
  3. In the appearing dialog, press OK to confirm the action, or Cancel.

Set Project Origin

  1. Select Set Project Origin from the ProKit > Transformer menu:
  2. Your cursor jumps to the current Project Origin. Drag, then click to place the new Project Origin.
