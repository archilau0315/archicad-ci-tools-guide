Annotate

Note: Not available in all markets

Use Annotate to batch-replace annotation attributes and text formatting across a project. Instead of editing elements one at a time, you define replacement rules once and apply them to the current view, a selection, a whole plan, or the entire project.

Annotate is intended for standards cleanup: bringing a project in line with an office template, or normalizing files and drawings that originated outside Archicad.

What you can change

  • Attributes: Fills, pens, and line types, optionally including attributes used by library parts
  • Text fonts: Individual fonts, or whole font families at once
  • Text case: A single case standard applied to the project's text strings, with defined "case exceptions" as needed (such as units, abbreviations, and proper nouns)

Workflow

  1. Define your rules in the relevant manager: Attribute Replacement Manager, Font Replacement Manager, or Case Exception Manager. Rules are stored with the project, and can be exported and reused in other projects.
  2. In the Annotation Replacement dialog, choose which kinds of replacement to run and which part of the project to apply them to.
  3. Click Replace.

Because a replacement can affect large parts of a project at once, run it on the current view or a selection first, verify the result, then widen the scope.

Annotate commands

Use the ProKit > Annotate menu:

  • Replace: opens the Annotation Replacement dialog, from which you can run a replacement and reach all three rule managers.
  • Manage Attribute Replacements, Manage Case Standards, and Manage Font Replacements: open the same three managers directly, for editing rules without running a replacement.
