Add Nails to a Detail Drawing

In this example, a detail has been drawn. To finish, it we just need to show the location of nails around the timber battens and box corner.

  1. Double-click the Detail Element tool
  2. From Detail Element Settings, select Nail 2D from the 08 Fastenings folder
  3. On the Nail 2D - Settings page, choose the Jolt Head Nail type.
  4. Set the nail dimensions, then click OK.
  5. Place the nail element onto the drawing, rotating it into the correct alignment as you place it.
  6. Place additional nails as needed.
