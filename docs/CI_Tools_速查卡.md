# CI Tools 速查卡（打印版）

**适用于 Archicad 24 及以上版本 · 各机器安装情况不同，先自查再上手**

---

## ⚠️ 每次新项目必做（3 步，1 分钟）

```
1. 文件 → 工作环境 → Ci Tools Profile XX → 应用
2. 文件 → 库管理器 → Add → 选 Ci Tools Macros.libpack（先这个）
   路径：C:\Program Files\Graphisoft\Archicad XX\Archicad 图库包\Ci Tools Library Packages\
   ★ 选单个 .libpack 文件，不要选文件夹
3. 其余 libpack 按需加载
```

---

## 工具箱没有图标？

```
右键工具箱空白处 → 工具箱设置 → 勾选 → ★保存工作环境
```

## 16 个工具一句话

| 工具 | 一句话 | 入口 |
|---|---|---|
| **Annotate** | 全项目文字大小写/字体批量改 | CI Tools → Annotate → Convert Case… |
| **Transformer** | 一键镜像整个项目（含2D标注） | CI Tools → Transformer → Mirror Project… |
| **Time Tracker** | 记工时对报价 | CI Tools → Time Tracker → Open Time Tracker |
| **Detail Elements** | 拖拽式二维详图库（10类） | 工具箱 → ProKit Detail Elements |
| **Keynotes** | 规范注释自动挂接+出明细表 | CI Tools → Keynotes → Keynotes Palette |
| **MetaData** | 属性/分类面板，批量改 | CI Tools → MetaData |
| **Quantities** | 算量出清单，Recipe 自动分配 | CI Tools → Quantities |
| **Cabinets** | 一个对象搞定所有橱柜 | 工具箱 → ProKit Cabinets |
| **Doors+Windows** | 异形门窗，尺寸捕捉 | 工具箱 → ProKit Doors+Windows |
| **Coverings** | 墙/板/柱贴3D皮，真实感↑ | 工具箱 → ProKit Coverings |
| **Electrical** | 智能电气符号+回路（无国标） | 工具箱 → ProKit Electrical |
| **Stairs** | 自由楼梯，栏杆可关联 | 工具箱 → ProKit Stairs |
| **Structural** | 桁架/框架/连接件 | 工具箱 → ProKit Structural |
| **Sites** | 场地边界/退让（澳新专属） | 工具箱 → ProKit Sites |
| **Fitout** | 房间一键配家具（客房神器） | 工具箱 → ProKit Fitout |
| **Bracing** | NZ木结构抗侧力（NZ专属） | 工具箱 → ProKit Bracing |

## 优先学这 3 个

```
1. Annotate     出图前文字统一 → 省几小时
2. MetaData     属性批量管理 → BIM交付必用
3. Time Tracker 算工时对报价 → 直接对钱
```

---

## 三个易踩的坑

```
① libpack 选成文件夹 → 内容全空。必须选单个 .libpack 文件
② 加了工具箱图标没保存工作环境 → 下次开 Archicad 没了
③ Annotate 改错 → 执行前 Ctrl+Z；先用"Selected items only"试手
```
