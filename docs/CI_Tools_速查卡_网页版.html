Archicad CI Tools 速查卡

16 个工具按优先级排序，配官方界面截图。适用于 Archicad 24 及以上版本。

每次新项目必做 · 3 步 1 分钟

STEP 01

加载工作环境

工具箱和菜单栏才会出现 CI Tools 条目

文件 → 工作环境 → Ci Tools Profile XX
STEP 02

加载图库包

90%「装了却用不了」的原因。必须选单个文件，不能选文件夹

文件 → 库管理器 → Add → Ci Tools Macros.libpack
STEP 03

加进工具箱

加完必须保存，否则下次开 Archicad 又没了

右键工具箱 → 工具箱设置 → 勾选 → 保存工作环境

图库路径（XX 换成你的版本号）：
Windows: C://Program Files\Graphisoft\Archicad XX\Archicad 图库包\Ci Tools Library Packages\
macOS: /Applications/Graphisoft/ARCHICAD XX/Archicad 图库包/Ci Tools Library Packages/ 先加载 Ci Tools Macros.libpack，它承载各工具的自动化宏。

先自查 · 你装了哪些

各机器、各 Archicad 版本安装情况不同，用之前先花一分钟确认。

查插件装没装

看 Add-Ons 目录里的 .apx 文件，一个文件对应一个工具

Windows: C://Program Files\Graphisoft\Archicad XX\Add-Ons\CI Tools\
查工作环境在不在

文件 → 工作环境，列表里有 Ci Tools Profile 就说明已就位

文件 → 工作环境 → Ci Tools Profile XX
装还没装怎么办

AC24~29 用 MyCi Installer；AC30 起用 Graphisoft 官网的 ProKit

cadimage.zendesk.com/hc/en-us

版本差异：AC29 起库包不再自动挂载，必须手动加载（见上方 STEP 02）；AC30 起工具包改名 ProKit，菜单名也随之改变。
试 30 天不花钱：myci.centralinnovation.com/freetrial

16 个工具 · 按该学的顺序

01Annotate

全项目文字大小写、字体批量改，出图前统一格式

第一优先 CI Tools → Annotate → Convert Case…
02MetaData

属性与分类的批量操作面板，BIM 数据管理主力

第一优先 CI Tools → MetaData
03Time Tracker

记录各任务工时，和报价、预期工时对比

第一优先 CI Tools → Time Tracker → Open Time Tracker
04Quantities

从模型出工程量清单，Recipe 自动分配数量成本

第二优先 CI Tools → Quantities
05Keynotes

规范注释数据库，按属性自动挂注释并出明细表

第二优先 CI Tools → Keynotes → Keynotes Palette
06Transformer

一键镜像整个项目，含 2D 标注和标签

第二优先 CI Tools → Transformer → Mirror Project…
07Detail Elements

拖拽式参数化二维详图库，10 大分类

按场景 工具箱 → ProKit Detail Elements
08Coverings

墙板柱贴 3D 覆面皮，自动跟随主体，汇报模型提质感

按场景 工具箱 → ProKit Coverings
09Fitout

房间一键配齐家具，酒店客房公寓布置神器

按场景 工具箱 → ProKit Fitout
10Sites

场地边界、退让高度关系评估，澳新专属

按场景 工具箱 → ProKit Sites
11Cabinets

一个可配置对象搞定所有橱柜，柜门抽屉面板库

按场景 工具箱 → ProKit Cabinets
12Doors+Windows

异形门窗样式，尺寸捕捉，样式可跨项目共享

按场景 工具箱 → ProKit Doors+Windows
13Stairs

自由楼梯设计，栏杆可关联，组合当单一对象输出

按场景 工具箱 → ProKit Stairs
14Structural

桁架、框架、连接件等 3D 结构构件库

按场景 工具箱 → ProKit Structural
15Electrical

智能电气符号与回路，库含欧盟英美印，无中国国标

按场景 工具箱 → ProKit Electrical

NZ 木结构抗侧力构件，符合 NZS 规范，新西兰专用

按场景 工具箱 → ProKit Bracing

三个最常踩的坑

01
libpack 选成文件夹 → 内容全空
库管理器里必须选单个 .libpack 文件，选文件夹层级只会挂载一层，工具打开是空的。这是官方明确警告的坑。
02
加了工具箱图标没保存工作环境
下次开 Archicad 又没了，每次都要重加。勾选后务必点保存工作环境。
03
Annotate 批量改错 → 撤不回来
执行前先 Ctrl+Z 备份。优先用「Selected items only」试手，参数勾「If displayed」最保险。

上手节奏

第一优先 · 立刻见效
  • Annotate出图前文字统一，省几小时
  • MetaData属性批量管理，BIM 交付必用
  • Time Tracker算工时对报价，直接对钱
第二优先 · 项目需要时
  • Quantities出算量清单
  • Keynotes规范注释系统，前期投入大
  • Transformer偶尔镜像时用
第三优先 · 特定场景
  • Coverings汇报模型提质感
  • Fitout客房批量布置
  • Sites澳洲场地评估

暂不建议碰：Cabinets、Doors+Windows、Electrical（无中国国标库）、Structural、Bracing（NZ 专用）。
