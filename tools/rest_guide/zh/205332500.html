有时你可能需要把一组工具装到没有互联网的电脑上，或者只是想在多台电脑上批量快速安装。

这个过程要先在一台有网的电脑上开始。

第 1 阶段：在联网电脑上创建离线文件

  1. 在一台已装好所需工具的电脑上，启动 Cadimage Installer。
  2. 选择 Create Offline Install File 选项。
  3. 点击 Create File。
  4. 为离线安装包选择保存位置和文件名。
  5. 选择工具要配用的 ARCHICAD 版本。
  6. 接着会看到工具清单——逐个点想打包工具旁的「Add」（或点 Add All 全选）。
  7. 点安装器右上角的 Save 按钮。
  8. 点 Quit 按钮。
  9. 从 myCadimage.com 下载一份 Cadimage Installer 和 Work Environment。
  10. 把 Installer、Work Environment 和离线安装包文件一起拷贝到目标电脑。

第 2 阶段：在离线电脑上

  1. 安装 Cadimage Installer。
  2. 安装 Cadimage Work Environment。
  3. 启动 Cadimage Installer。
  4. 出现提示时，确认「Install Cadimage Tools」和「Offline」都处于勾选状态。
  5. 点击 Open Install File 按钮。
  6. 找到之前拷贝过来的离线安装文件。
  7. 选择要安装的工具。
  8. 完成后退出安装器。
