打开支撑类型管理器（Ci Tools > Bracing > Bracing Types Manager）。

在 Ci Tools Bracing Types 窗口中，选择你常用的支撑集，点 New。

输入支撑的名称和支撑参数：

Composite Prefix（复合结构前缀）：INT 仅限内墙，EXT 仅限外墙，INT/EXT 表示内外墙均可使用。

输入描述。

设置长度（务必勾选 Maximum）。

把支撑单位改为 Fixed（固定）。

设置最小长度、Wind Bus（风荷载等效值）和 EQ Bus（地震等效值）。

点 OK。

回到平面图后，选中要改为新支撑类型的支撑构件并打开其设置。

在选项中进入 Configuration，选择刚创建的新支撑类型，点 OK。

选中支撑表，然后进入 Ci Tools > Bracing > Update Brace Tables。
