本文介绍如何为 Archicad 29 技术预览版（Technical Preview）安装 Ci Tools。
请注意：Ci Tools 和 Archicad 本体一样处于预发布状态，尚未完成全部测试，可能存在未知问题。
多数情况下我们推荐使用 CI Tools Library Packages 库；如果你确实需要旧的「monolith」库，我们也提供了对应版本，位于「Ci Tools Monolith Migration Library」文件夹。
与 Archicad 28 一样，「Migrate Library Parts」功能可用于需要「完整」迁移的场合——操作说明见此——请仅在确有必要时使用。多数情况下，直接加载旧库即可继续项目。

获取 Ci Tools 的方法：
  1. 按你的操作系统用以下链接下载压缩包：
    • Windows：点此下载
    • Macos：点此下载
  2. 下载后打开/解压 ZIP 文件。
  3. 做第 4 步前，请确保 ARCHICAD 没有在运行。
  4. 安装工具只需把文件拷到电脑上正确的位置：
    • 把解压出的 CI Tools 文件夹移入 Archicad 29 Technology Preview\Add-Ons 文件夹
    • 把解压出的 CI Tools Library Packages 文件夹移入 Archicad 29 Technology Preview 文件夹
    • 把解压出的 Ci Tools Monolith Migration Library 文件夹移入 Archicad 29 Technology Preview 文件夹
如果工具出现问题，请把报告发邮件给支持团队 nz.support@centralinnovation.com，并注明你使用的是 v29 技术预览版。
