Open the bracing Types manager (Ci Tools > Bracing > Bracing Types Manager)

Next in the Ci Tools Bracing Types window, Select the Bracing set you commonly use, and click New.

Enter the Name of your Brace & the bracing details.

Composite Prefix (INT for internal only, EXT for external only, INT/EXT for a brace that can be used on either INT or EXT)

Enter a description,

Set the Length (ensure to tick Maximum)

Change the Bracing units to Fixed

Set the min length, Wind Bus & EQ Bus

Click Ok

Once back on your floor plan, select and open the settings of bracing element you want to now be your new Brace type.

In the options go to Configuration and select the new Brace Type you created then Click OK

Select the Bracing Table then go to Ci Tools > Bracing > Update Brace Tables.
