This document covers how to install the Ci Tools for the Archicad 29 Technical Preview
 
Please note that the Ci Tools, as with Archicad itself, are in a pre-release state. They have not been fully tested yet, and so may contain issues that we don’t know about yet
 
In most cases, we recommend using the CI Tools Library Packages libraries, but if you do require the older 'monolith' libraries, we have also made a version of these available in the "Ci Tools Monolith Migration Library" folder
 
As with Archicad 28, the "Migrate Library Parts" function is available to assist in cases where you need to do a 'Full' migration - instructions are available here - please only do this if you really need to. For most cases, simply loading your old library is fine for continuing projects.

 
Here’s how to get the Ci Tools:
 
  1. Download the pack for your Operating System using the following links:
    • Windows: Download Here
    • Macos: Download Here
  2. Once downloaded, open/extract the ZIP file
  3. Before doing step 4 - please ensure that ARCHICAD is not running
  4. To actually Install the tools, you now just need to copy the files into the correct places on your computer:
    • Move the extracted CI Tools folder into your Archicad 29 Technology Preview\Add-Ons folder
    • Move the extracted CI Tools Library Packages folder into your Archicad 29 Technology Preview folder
    • Move the extracted Ci Tools Monolith Migration Library folder into your Archicad 29 Technology Preview folder
If you encounter any bugs with the tools, please let our support team know by emailing your report to nz.support@centralinnovation.com, and make sure to tell them that you are using the v29 Technical Preview
