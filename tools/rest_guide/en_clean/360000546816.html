The Cadimage Bracing Tool is an NZ ARCHICAD users only tool that will help you set out your bracing solution for timber-framed buildings under NZS 3604. 
 
It’s highly recommended that you have an understanding of NZS 3604 and have a copy available for reference unless you have memorized it!
 
Once you’ve set your calculation settings the tool with place Bracing Lines, Bracing Elements & a Bracing Table. You will still have to add, edit, modify the correct data & objects to ensure your bracing design meets all of the relevant New Zealand Building Codes and Standards.
 
The Bracing Tool does require wall that is designed using the composites and has the prefix EXT or INT
