打开 Quantities Info 面板：菜单 CI Tools > Quantities > Quantity Take-off Palette…

面板顶部与 ARCHICAD 的 Info（信息）面板类似，显示已选中、可编辑的构件数量。旁边的 Live Edit（实时编辑）勾选框会显著改变面板的用法：

  • Live Edit 开启时，用法与 ARCHICAD 的 Info 面板基本一致：

    • 内容随当前选择动态更新；

    • 没选构件但选了工具时，显示该工具的设置；

    • 编辑立即作用于选中构件或当前工具设置；

    • 工具和构件都没选时，只显示 No selection，不做任何事；

    • 可以把构件选择集筛选为匹配所选特征标记的子集；

    • 也可以把匹配所选特征标记的构件扩充进选择集。

  • Live Edit 关闭时，面板转为被动角色，用于管理或转移设置：

    • 内容只能由面板自身的控件改变——选择操作不影响内容；

    • 可以从选中构件提取特征标记；

    • 可以把特征标记注入到构件里（可选哪些）；

    • 可以在新构件加入项目时自动套用特征标记（不限类型）。

面板其余部分分三段，均可折叠：

  1. Quantities 配方

  2. ARCHICAD 属性

  3. ARCHICAD 分类

三个分区的操作方式基本相同，不必逐一详述。本节概括面板的通用功能，具体操作见后续各节。构件特征标记由以下面板按钮管理：

Live Edit 开

Live Edit 关

添加特征标记

仅在选中构件或工具时可用。提示选择一个或多个特征标记，并立即加到选中构件或工具上。详见 2.3.1

提示选择一个或多个特征标记，加到对应的面板列表里。不影响选中的构件或工具。详见 2.3.4

移除特征标记

仅在面板列表中选中了特征标记时可用。立即从选中构件或工具上移除所选特征标记。详见 2.3.2

仅在面板列表中选中了特征标记时可用。立即从面板列表中移除所选特征标记。不影响构件或工具

提取特征标记

此场景不适用

仅在选中构件或工具时可用。从选中工具或构件提取全部相关特征标记并显示在列表里。构件与工具本身不受影响。详见 2.3.3、2.3.4

注入特征标记

此场景不适用

仅在选中构件或工具时可用。把列表中的相关特征标记注入选中工具或构件；若列表里有选中项，则只注入这些项。详见 2.3.3、2.3.4

选择匹配项

在面板列表选中至少一个特征标记时可用。立即在当前视图中选中具有匹配特征标记的构件（追加到当前选择集）。详见 2.3.5

此场景不适用

按特征标记筛选

在面板列表选中至少一个特征标记时可用。立即筛选已选构件，只保留特征标记匹配的那些。详见 2.3.6

此场景不适用

管理配方

打开 Quantity Take-off Manager（工程量提取管理器）并定位到 Recipes（配方）页，快速编辑配方、度量规则与计算。

清单算量

打开 Bill of Quantities 面板。若有选中构件，则为该选择集生成清单，便于快速核对构件是否产出预期的工程量。

注意，列表中特征标记的文字样式在某些情况下会有变化。通常所有条目都是普通黑色字，但可能出现以下样式（有时会叠加）：

红色

仅与配方相关。配方名显示为红色，表示它是手工加到构件上的，但随后在工程量提取管理器里被删除了。这个警告可能提示该配方不该删——那样的话可以在管理器里恢复；如果配方确实多余，可以把它从构件上移除。注意：被删除的配方只要还挂在构件上，就不影响度量过程。

斜体

仅与配方相关。配方名显示为斜体，表示它是被度量规则自动加到构件上的。例如某条规则要求挂到所有墙上，那么墙就会以斜体显示该配方名。

蓝色

仅在选中多个构件时出现。名称显示为蓝色，表示它并非整个选择集共有——即选择集中至少有一个构件没有这个特征标记。这同样适用于单个属性值：选中的构件可能都有这个属性，但值不一样。详见 2.4.2。

加粗

仅与属性相关。属性名显示为加粗，表示该属性在多个构件中都存在但取值不同。
