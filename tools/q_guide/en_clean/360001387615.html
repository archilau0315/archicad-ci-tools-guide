The settings for new elements is usually governed by the Settings dialog for the relevant tool. The ARCHICAD Info and Quantities Info palettes also provide an interactive view on those settings, but these settings are never shared by multiple tools.

However, the Quantities Info palette can apply traits to new elements of any type when Live Edit is turned off. Any traits displayed in the palette will be added to every new element irrespective of type. This action can be prevented by either clearing the palette list or collapsing the relevant panel. The data in the Settings dialog remains unchanged.

This feature is beneficial when a series of elements must share certain traits or values because it removes the need to open multiple Settings dialogs to repeatedly make the same change.
