The text style of traits listed in the Quantities Info palette provides important feedback about the their status. For example:

  • Blue indicates that the trait is not common to the selected elements, which is useful for spotting traits that are supposed to be uniform. ARCHICAD’s Find & Select palette is useful in conjunction with this feature, first finding elements that should be identical and then checking Quantities Info for inconsistencies.
  • Red indicates that a manually applied recipe has been deleted, suggesting a mistake.
  • A bold face is used wherever a property has multiple values across the selected elements. The values can be viewed by clicking the disclosure triangle.

When an anomalous trait or property value is spotted, the contributing elements can be isolated by selecting the traits/values in the list and clicking the filter by traits button
