ARCHICAD already provides a method for extracting data from one element and injecting it into another, but this is too coarse-grained for managing costing data – particularly property values. The Quantities Info palette allows any selection of traits to be applied or transferred to selected elements, even allowing just a single property value to be changed. This method is only applicable when Live Edit is off.

The palette can be populated with the traits of selected elements by clicking the extract button (). These traits can be transferred into other elements by selecting them and clicking the inject button (). If no traits are selected in the palette list, the entire list of traits replaces everything previously assigned to the element (so traits may be both added and removed). If some are selected in the list, only the selected traits are injected (and nothing is removed).

Note that the list of traits in the palette isn’t limited to those extracted from other elements – they can be freely added (section 2.3.1) or removed (section 2.3.2). Some additional detail for managing properties is provided in section 2.4.8.
