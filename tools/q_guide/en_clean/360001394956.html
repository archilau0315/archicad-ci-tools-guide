Traits can only be directly removed from elements when Live Edit is on. Select the target elements, select the traits to be removed in the palette list and click the delete button ().


Clicking the delete button when Live Edit is off simply removes the selected traits from the palette list (selected elements are unaffected), but traits can be indirectly removed by injecting a fixed list of traits into selected elements (refer to section 2.3.3). Section 2.4.5 provides more detail for deleting properties.
