The add-on appends a panel for to ARCHICAD’s standard Settings dialog for editing the recipes manually attached to an element:

This panel may have to be shown use the Work Environment settings. Recipes can be added by clicking the add button (), or selected recipes removed by clicking the delete button (). Warning: if the recipes of multiple elements are edited with the Settings dialog, they will all end up with the same recipe list (as shown in the Settings dialog) irrespective of whatever recipes were attached previously. For this reason, it is generally recommended to use the Quantity Take-off palette, because the traits of multiple elements can be edited non-destructively.

The option for Manual recipes only can be set to prevent any recipes from automatically attaching to the element (refer to section 4.5, Automatic Measurements for more information). Only manually attached recipes will take measurements when this option is set.
