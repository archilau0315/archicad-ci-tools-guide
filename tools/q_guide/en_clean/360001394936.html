Select the target elements, click the ‘add’ button () under the relevant list and select the traits to be added when the list appears:

Multiple items can be selected and added in one step, but note that only one classification can be added per system. When Live Edit is active, the selected traits are immediately added to the selected elements.


An additional step is required if Live Edit is off. Select the traits to be added in the palette list and click the inject button (). Note that it is very easy to repeat this action on subsequent element selections when Live Edit is off because the palette list is unaffected by element selection or view changes.


Note that is is possible to added recipes using ARCHICAD’s Settings dialogs (refer to section 2.3.8). Section 2.4.4 provides more detail for adding properties.
