Adding a property is essentially the same as adding any other trait, but there is an important difference. Properties are associated with elements on the basis of their classification – therefore, the only way to add a property to an element is to change the classification it is associated with, i.e. by adding the property to the classification. Quantities will do this automatically to facilitate adding a property. The change is non-destructive and undoable, but it is important to understand that adding a property to an element will likewise affect other elements with the same classification.

Properties can be added to multiple elements simultaneously, which may result in changes to multiple classifications.
