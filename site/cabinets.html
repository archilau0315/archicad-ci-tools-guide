（ARCHICAD 22）如何创建自定义旋钮

(ARCHICAD 22) How to Create a Custom Knob

MyCi 官方原文 ↗

Cadimage Cabinet 可以使用由标准 ArchiCAD 构件创建的自定义旋钮。

创建自定义旋钮的步骤：

  • 在平面视图中使用楼板（slab）、柱（column）、墙体（wall）等绘制旋钮。
  • 确保笔和材质已按你希望成品旋钮呈现的样子设置好。
  • 旋钮的朝向应如同你在立面中观察它时的样子。这意味着在 3D 中查看时它将立在其连接表面上。
  • 从 ArchiCAD 的 File 菜单中选择 Libraries and Objects > Save Custom Component。
  • 选择 Custom Knob（自定义旋钮）类型。
  • 输入旋钮名称，并将其保存到嵌入式库（Embedded Library）中。

保存旋钮后，现在就可以将其作为 Cadimage Cabinet 的一部分来使用。

  • 打开橱柜的 Settings（设置）对话框，将 Handle（把手）类型选择为 Custom Knob。
  • 在 Doors & Drawers > Handles 和 Doors & Drawers > Place Handles 下调整位置、尺寸和朝向。
  • 把手现在就会出现在橱柜的门或抽屉上。

The Cadimage Cabinet can use custom knobs created from standard ArchiCAD elements.

To create a custom knob:

  • Draw the knob in plan view using slabs, columns, walls, etc.
  • Ensure the pens and materials are set as you want them to appear in the finished knob.
  • The knob should oriented as if you are viewing it in elevation. This means it will be standing on its connecting surface when viewed in 3D.
  • From ArchiCAD's  File  menu, choose  Libraries and Objects > Save Custom Component .
  • Choose the  Custom Knob  type.
  • Enter a name for the knob, and save it into the embedded library.

Having saved the knob, now you can include it as part of a Cadimage Cabinet.

  • Open the cabinet's Settings dialog, and choose the  Handle  type to be a  Custom Knob .
  • Adjust the position, dimensions and orientation under  Doors & Drawers > Handles  and  Doors & Drawers > Place Handles .
  • The handle will now appear on the cabinet's doors or drawers.

提示： 由于虚线长度是由对象绘制的，而非作为"虚线"放置的，你可能需要检查剖面图和内部立面图，以确保其与你所使用比例相符。

在此你可以设置 Plan View Label（平面视图标签）：

在此区域你可以添加 Full Label Text（完整标签文本）和 Short Label Text（简短标签文本）的内容，以及标签是否随橱柜一起旋转。

提示： 平面图显示通过 Cadimage Cabinets 的 Model View Options（模型视图选项）控制。这些数据也可用于编表用途。

Both of these options allow you to control the performance of the model. High resolution cabinets look the best – but may be difficult for your computer to work with if you have a number of them. By decreasing the resolution you will improve the performance of the 3D Window as well as 3D generated views such as sections or elevations.

In a similar way, if you have large numbers of cabinets on plan, a ‘Projection’ will have slower performance than a symbol based view. This is because the projection needs to generate the 3D view in order to display the plan view symbol. The symbol on the other hand uses a script to show a symbolic view of the cabinet.

使用 CI Bench Top 对象可为橱柜添加台面。

添加台面

  • 在 Configuration（配置）页面，设置基本选项：

  • Nosing Profile（封边轮廓）

  • 在 Graphic Editing（图形编辑）选项中，选择 Shape（形状）。

编辑形状

由于你在上面第 2d 步中为 Graphic Editing（图形编辑）选择了 Shape（形状）选项，编辑调色板此时已显示用于编辑台面形状的选项。

How to Change Module Settings

MyCi 官方原文 ↗

每个橱柜都包含一个或多个模块（module）。若要了解如何将橱柜划分为多个模块，请参阅文章如何以图形方式划分橱柜和如何在设置对话框中划分橱柜。

一个模块由三个基本组成部分构成——类型（Type）、面板（Front）和把手（Handle）。

对于每个模块，你都可以为这三部分分别选择样式。这样便可将一个模块设为门、另一个设为抽屉组、第三个设为抽拉式收纳箱。它们可以采用相同的面板样式，你也可以独立选择各模块的面板样式。同样，你也可以为每个模块独立选择把手样式。

要更改模块类型、面板和把手：

  • 选中橱柜并打开其设置对话框。

  • 在 Modules 页面，点击以选中要编辑的模块。

  • 从列表中选择模块类型、面板和把手。

为模块设置其他一些数值（即更改 Label（标签）、设置 Opening（开启）角度／间隙，并选择把手位置）。

  • 点击 OK 应用设置。

可用模块类型

要编辑可用模块类型列表，请转到 Modules > Available Module Types（模块 > 可用模块类型）页面。

在此页面上操作时，3D 预览仅显示所选模块类型的示例。

在此你可以：

  • 重命名模块类型
  • 删除模块类型（前提是当前未在使用）
  • 添加新的模块类型
  • 调整模块类型的设置

可用面板

要编辑可用面板列表，请转到 Modules > Available Fronts（模块 > 可用面板）页面。

在此页面上操作时，3D 预览仅显示所选面板的示例。

在此你可以：

  • 重命名面板。
  • 删除面板（前提是当前未在使用）
  • 添加面板
  • 调整面板的设置

面板的设置包括：

  • Style（样式）—— 有多种基本框料形状可选。请注意，Framed 形状遵循门的形状（通常为矩形，除非放置在 Ci Cabinet Polygon 对象中）。
  • Panel type（面板类型）—— 选择面板类型（如玻璃、企口拼板等）。根据所选面板样式设置尺寸。
  • 对于玻璃面板，选择窗棂（muntins）样式以及窗棂／玻璃格条的尺寸。
  • Surfaces（表面）
  • 横档（rails）的尺寸和面板形状（如果有）。

可用把手

要编辑可用面板列表，请转到 Modules > Available Handles（模块 > 可用把手）页面。

在此页面上操作时，3D 预览仅显示所选把手的示例。

在此你可以：

  • 重命名把手。
  • 删除把手（前提是当前未在使用）
  • 添加把手
  • 调整把手的设置

请注意，这些设置不仅包括把手的形状和尺寸，还包括其表面。

创建自定义空间填充物的步骤：

  • 建模（或获取）你想放入的物件的模型。应使用基本 Archicad 元素（如 slab、wall、mesh、morph）建模，而不是使用库部件。

  • 为新的空间填充物输入名称。
请注意，你可以将空间填充物的边界框尺寸附加到文件名后，例如 *MyTeapot_213x160x175mm*。这些尺寸应当： - 以下划线字符开头。 - 按 x、y、z 的顺序排列。 - 以 x 字符分隔。 - 后面跟 mm 或 inch 以标明单位。如果你这样做，每次选择该空间填充物时都会自动应用正确的尺寸。

使用上面创建的空间填充物：

  • 选中要放入空间填充物的橱柜。
  • 打开橱柜的 Settings（设置）对话框。
  • 在 Spaces > Available Filler Types（空格 > 可用填充物类型）页面，点击 + 按钮添加新的填充物类型。
  • 输入 Name（名称），并将 Type（类型）设置为 Custom Space Filler。
  • 从列表中选择你创建的空间填充物。
  • 如果你没有在空间填充物的文件名中包含边界框尺寸，或者想更改尺寸，请手动设置尺寸。
  • 在 Spaces 页面，选中一个或多个空格，然后选择在步骤 1 - 6 中创建的新空间填充物类型。

There are a (growing) number of different space filler types (wine rack, plate rack, glassware, books, etc.) built into the cabinets. However, if you want to place something completely different into a cabinet, you can always create a Custom Space Filler.

To create a custom space filler:

  • Model (or obtain a model of) the item you want to include. This should be modeled using basic Archicad elements (e.g. slab, wall, mesh, morph) rather than a library-part.
  • Select the model in plan view.
  • From the File menu, choose Libraries and Objects > Save Selection As ... and choose the type to be Cabinet Space Filler.
  • Enter a name for the new space filler.

The dimensions should: - Begin with an underscore character. - Be in the order x , y , z . - Be separated with the x character. - Be followed by either mm or inch to indicate the unit. If you do this, whenever you select the space filler, the correct dimensions will be applied.

  • Select the cabinet into which you want to place the space filler.
  • Open the cabinet's Settings dialog.
  • On the Spaces > Available Filler Types page, click the + button to add a new filler type.
  • Enter a Name , and set the Type to Custom Space Filler .
  • Choose the space filler you created from the list.

  • On the Spaces page, select one or more spaces, and choose the new space filler type you created in steps 1 - 6.

  • 完全位于剖切平面之下。
  • 完全位于剖切平面之上。

完全位于剖切平面上方的橱柜将显示为简单的轮廓，……

…… 使用 Model View Options > Ci Cabinets > Attributes 设置中定义的 Above Cutting Plane（剖切平面之上）线型和笔。

在这种情况下，完全位于剖切平面下方的构件将表现得如同完全位于剖切平面之上，反之亦然。

单元分隔（Unit Partitions）

显示单元分隔

显示单元分隔以便在平面视图中识别相邻单元的范围。

  • 完全位于剖切平面上方的橱柜将显示延伸至柜体底部的单元分隔。
  • 完全位于剖切平面下方的橱柜将显示延伸至柜体顶部的单元分隔。

如何定义剖面、立面或 3D 视图

How to Define a Section, Elevation or 3D View

MyCi 官方原文 ↗

Ci Cabinets 工具提供了 Model View Options（模型视图选项），用于控制橱柜在剖面、立面和 3D 视图中的显示方式。这些设置都位于 Model View Options > Ci Cabinets 对话框的 Model（模型）页面上。

使用这些选项可以让每个视图显示恰当的信息，并减少多边形数量。

门与抽屉（Doors & Drawers）

控制门和抽屉的设置出现在模型视图中，包括：

  • All Shut（全部关闭）—— 所有门和抽屉都将显示为关闭状态，即使在橱柜的设置对话框中设置为开启。
  • Show Opening Lines（显示开启线）—— 控制是否显示门和抽屉的开启线，以及开启线的显示方式。

空间填充物（Space Fillers）

Show in View（在视图中显示）—— 选择是否在当前视图中显示空间填充物。

空间填充物在表现图中可能很有用，但在带尺寸标注的图纸中你多半不希望显示它们。空间填充物通常也包含较多多边形，因此能将其从除少数关键视图之外的所有视图中移除，有助于控制多边形数量。

模块面板（Module Fronts）

模块面板的选项包括：

  • Show in View（在视图中显示）—— 选择在给定视图中显示／隐藏模块面板。通常你会希望显示面板，但某些视图中你可能只想显示柜体。
  • Transparency（透明度）—— 设置模块面板的透明度，以部分显露被遮挡的构件。
  • Show Handles（显示把手）—— 显示把手（你可能希望隐藏把手以减少多边形数量）。
  • Show Labels（显示标签）—— 显示／隐藏每个模块上的可选标签。

内部构件（Internal Components）

橱柜的某些构件（如层板、可调柜脚、空间填充物）在门和抽屉关闭时会被非玻璃面板遮挡，或被踢脚板遮挡。对于 3D 视图或内部立面图而言，由于这些细节实际不可见，生成全部这些隐藏细节可能并无意义。

使用 Show in View 选项有助于控制那些不需要隐藏层板、分隔、柜脚和空间填充物的视图中的多边形数量。

层板（Shelves）

层板和分隔可以显示为绘制在橱柜面板上的隐藏细节线。

The Ci Cabinets tool provides Model View Options that control how cabinets are displayed in section, elevation and 3D views. These settings are all available on the Model page of the Model View Options > Ci Cabinets dialog.

Use these options to tailor each view to display appropriate information, and to reduce the polygon count.

Doors & Drawers

Settings that control doors and drawers appear in the model view, include:

  • All Shut - all the doors and drawers will be displayed as shut, even if set to open in the cabinet's Settings dialog.
  • Show Opening Lines - control whether to display opening lines for doors and drawers, and how the opening lines should appear.

Space Fillers

Show in View - choose whether to display space fillers in the current view.

Space fillers can be useful in a presentation view, but you probably don't want to display them in a dimensioned drawing. Space fillers also tend to be polygon-heavy, so it's nice to be able to keep the polygon count in check by removing them from all but a few key views.

Options for module fronts include:

  • Show in View - choose to show/hide the module fronts in a given view. Generally you'll want to show the fronts, but there may be some views for which you only want to show the carcass.
  • Transparency - set the transparency of module fronts, to partially reveal hidden components.
  • Show Handles - show the handles (you may want to hide them to reduce the polygon count).
  • Show Labels - show/hide the optional labels on each module.

Internal Components

Some components of a cabinet (e.g. shelves, adjustable legs, space fillers) are hidden behind non-glazed doors and drawers when closed, or behind the plinth. For 3D views, or for interior elevations, it may not be helpful to generate all of this hidden detail, given that it's not actually visible.

Use the Show in View option to help control the polygon count for views that don't require hidden shelves, partitions, legs and space fillers.

Shelves and partitions may be shown as hidden detail lines drawn on the cabinet fronts.

如何以图形方式划分橱柜

MyCi 官方原文 ↗

可以在橱柜中插入分隔（Partitions），将其划分为单元和模块，并在模块内添加层板和横向隔板。为了有效使用 CI Cabinet 工具，你需要了解如何操作分隔。

请注意，分隔也可以在库部件的 Settings（设置）对话框中添加、移除和移动——参见如何在设置对话框中划分橱柜。

CI Cabinet 对象的特殊功能

CI Cabinet 对象提供了一些特殊功能，便于在平面视图中快速放置一组矩形单元。这支持一种工作流程：多个单元作为一个整体绘制出来，从而在不为各单元单独编表的前提下表达设计意图。

调整橱柜宽度时添加分隔

首次放置时，Ci Cabinet Linear 包含一个单元。

在 Grids & Editing（网格与编辑）页面下的 Cabinet Width Adjustment（橱柜宽度调整）选项中，选择在平面视图中拉伸橱柜时的行为方式。

在 Cabinet Width Adjustment 下，选择增加橱柜宽度时应插入的分隔类型：

  • Insert Unit Partitions（插入单元分隔）—— 每当橱柜宽度超出默认间距时插入一个单元分隔，前提是剩余宽度大于最小间距。
  • Insert Module Partitions（插入模块分隔）—— 每当橱柜宽度超出默认间距时插入一个模块分隔，前提是剩余宽度大于最小间距。
  • Insert No Partitions（不插入分隔）—— 橱柜宽度调整时不插入分隔。

使用橱柜前端处的端点热点来调整橱柜宽度。额外的单元会以固定间隔添加。

每当橱柜长度超出 Default Width（默认宽度）时，就会插入一个新的单元分隔。最后一个单元将填满剩余空间。如果剩余空间过窄（即小于 Minimum Width，最小宽度），则最后一道分隔会被省略，从而形成更宽的单元。

在平面视图中移动单元分隔

将橱柜拉伸到正确长度后，可以调整单元分隔的位置。

  • 选中橱柜，点击要移动的单元分隔后缘上的动态热点。

  • 移动分隔并点击放置热点，或通过键盘输入位置。

在平面视图中添加单元分隔

你可以在平面视图中添加竖向的单元分隔。

  • 在平面视图中选中橱柜。

  • 打开库部件的设置对话框，在 Grids & Editing 页面将 Editing Palette > Edit Mode（编辑调色板 > 编辑模式）设置为 Partitions（分隔）。

  • 点击 OK。编辑调色板将出现在橱柜旁边。

  • 将单元分隔图标从调色板拖入橱柜平面视图中，即可添加分隔。

  • 将调色板滑块移到 X 位置以隐藏调色板。

在平面视图中移除单元分隔

要移除竖向的单元分隔：

  • 在平面视图中选中橱柜。

  • 点击单元分隔后缘上的热点，并将分隔拖出橱柜。该分隔将消失。

CI Cabinets 库中的所有橱柜都提供使用竖向和横向分隔来分割橱柜的功能。每道分隔都可以定义单元或模块的边界，也可以定义层板或隔板的位置。

添加分隔

  • 在 Grids and Editing 页面，将 Editing Palette > Edit Mode 设置为 Partitions，然后点击 OK。

  • 你会注意到一些变化：

  • 单元分隔（横向）

  • 模块分隔——封闭（横向）—— 在柜体内包含分隔墙
  • 模块分隔——开放（竖向）—— 无分隔墙
  • 模块分隔——开放（横向）—— 无分隔墙
  • 内部隔板（竖向）—— 模块内的竖向隔板
  • 内部层板（横向）—— 模块内的层板或横档
  • 从编辑调色板将一个热点拖到橱柜的正面。在此过程中你会看到在热点位置生成了一个分隔。

  • 将热点放在所需位置即可创建分隔。

  • 你可以继续添加任意数量的分隔。完成后，将调色板滑块移到 X

  • 编辑调色板将消失，橱柜将以完整细节显示。

移动分隔

每道分隔都有一个动态热点，允许你在橱柜内移动它。

要移动分隔：

  • 转到 3D、剖面或立面视图。

  • 选中橱柜。

  • 拖动分隔热点以移动分隔。

移除分隔

要移除分隔，只需将其移到橱柜外部即可。

将分隔对齐到网格

使用 Align Partitions to Grid（将分隔对齐到网格）选项可以更轻松地确定分隔的精确位置。

在 Grids & Editing 页面设置 Anchor & Spacing（基准与间距）设置。例如，你可能希望在 X 和 Y 方向都捕捉到最近的 50mm，并将网格锚定到柜体的左下角。选择捕捉的邻近范围（位于该范围内的分隔将捕捉到网格线）。

设置完成后，点击 Align Partitions to Grid 复选框。

现有分隔将捕捉到网格；移动分隔时，只要处于所选邻近范围内就会捕捉到网格线。

  • Insert Module Partitions - a module partition will be inserted whenever the cabinet's width increases beyond the default spacing, provided the remaining width exceeds the minimum spacing.
  • Insert No Partitions - the cabinet width will adjust without inserting partitions.

Overview

MyCi 官方原文 ↗

Ci Cabinets 工具提供设计自由度，让你在建筑信息模型（BIM）中创建并记录木作。

术语表（Glossary of Terms）

以下术语用于文档和用户界面：

Cabinet（橱柜）完整的橱柜结构（可进一步细分为*单元*和*模块*）。
Partition（分隔）橱柜可沿竖向和横向线条分割。这些线条中的每一条称为*分隔*。分隔可以有不同类型——*单元*、*模块*、竖向*隔板*或横向*层板*。
Unit（单元）交付到现场的实体。它可细分为*模块*。每个单元包括两端的墙体、底板和顶板。
Module（模块）单元内部的划分。相邻模块之间可能有分隔墙（例如两个相邻的柜柜模块具有各自独立的内部空间），也可能没有分隔墙（例如抽屉组中的两个抽屉通常不会由分隔隔开）。每个模块都有一个*类型*、一个*面板*和一个*把手类型*。
Module Type（模块类型）每个模块都有一个控制其功能的*类型*（如门、抽屉、开放搁板、抽拉式收纳箱）
Front（面板）与模块的门、抽屉面板等关联的面板样式。
Handle（把手）模块所用的把手类型。
Shelf（层板）模块内部的水平划分。它可以是固定层板、板条、抽拉托盘或横档。
Vertical Divider（竖向隔板）模块内部的竖向隔板。
Face（面板）橱柜的前端面。
Plinth（踢脚板）沿落地橱柜正面延伸的"趾脚挡板"。
Muntins（窗棂）可应用于玻璃面板的玻璃格条样式。
Space（空格）柜体墙体、顶板、底板、分隔、层板和竖向隔板在橱柜内形成*空格*。每个这样的空格都可以填入*空间填充物*。
Space Filler（空间填充物）用于表现效果物件，如玻璃器皿、餐具、储物罐和酒架。

Cabinets 工具可快速便捷地创建非常细致的橱柜模型。它既支持放置简单的"占位式"橱柜，也支持用于出图和制造的复杂专属橱柜设计。

参考指南 — 橱柜配置

在 Configuration（配置）选项卡中可设置橱柜的整体尺寸。

  • 也可以锁定橱柜的某个特定部分以便调整。

（该选项将呈灰色不可用。）

  • 也可以在此选项卡中设置整体的面板（Face）与踢脚板（Plinth）选项。
  • 模型中使用的表面也可以在此设置。

面板（Face）

在 Face 菜单选项下，可以调整面板各方面的宽度和外观。

  • 面板类型可选择 Frameless（无框）、Inset（嵌入式）、Half Overlay（半覆盖）和 Full Overlay（全覆盖）。

下面我们逐一了解。

Frameless（无框）

  • 可调整橱柜内部框体的尺寸。
  • 可设置门之间的所有间隙（tolerance）。

Inset（嵌入式）

这意味着门会被嵌入柜体（Carcass）之中。

  • 门、抽屉等周围框料的所有尺寸均可调整
  • 框料与所选门、抽屉等之间的间隙均可调整。

Half Overlay（半覆盖）

  • 门、抽屉等周围框料的所有尺寸均可调整
  • 框料与所选门、抽屉等之间的间隙均可调整。

Full Overlay（全覆盖）

  • 门、抽屉等周围框料的所有尺寸均可调整
  • 框料与所选门、抽屉等之间的间隙均可调整。

柜体（Carcass）

与面板设置一样，底层柜体的尺寸完全可调。

  • 可设置柜体的尺寸。
  • 可设置与边缘的缩进量（Inset）。

踢脚板与柜脚（Plinth and Legs）

踢脚板与柜脚设置提供了多种选项，用于决定橱柜如何安装在地面上。

  • 首先可以选择踢脚板类型。

可选择 Adjustable Legs（可调柜脚）、Extend Walls（延伸侧板，即橱柜的侧墙）、Inset from Cabinet（相对橱柜缩进）或 No Plinth（无踢脚板）。

Adjustable Legs（可调柜脚）

  • 可设置踢脚板的趾部空间（Toe Space）和高度。
  • 可设置柜脚的尺寸和直径。
  • 可调整柜脚的位置。

Extend Walls（延伸侧板）

  • 可设置踢脚板的趾部空间和高度。

Inset from Cabinet（相对橱柜缩进）

  • 可调整与四边的缩进量。

No Plinth（无踢脚板）

不显示踢脚板，柜体将安装在楼层标高处。

背板与端板（Back and End Panels）

还可以设置多种背板与端板，以适配所有配置类型。

  • 可选择背板及其类型
  • 可选择侧板的变化形式及其类型。

  • Tolerances between the Framing and the chosen door, drawer etc. can be adjusted.
