每次新项目必做 · 3 步3 steps for every new project

STEP 01

加载工作环境Load Work Environment

菜单栏和工具箱才会出现 CI Tools 条目

Makes the CI Tools entries appear in the menu and toolbox

File > Work Environment > Ci Tools Profile XX
STEP 02

加载图库包Load Library Packs

AC29 起必须手动加载，否则工具内容为空

From AC29 library packs must be loaded manually, or tools appear empty

File > Library Manager > Add > Ci Tools Macros.libpack
STEP 03

加进工具箱Add to Toolbox

加完必须保存，否则下次开 Archicad 又没了

Remember to save the work environment, or it resets next launch

Right-click Toolbox > Toolbox Settings > tick > Save Work Environment
