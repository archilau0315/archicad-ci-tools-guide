工具概览：NZS 3604 木框架支撑设计

Overview of the Cadimage Bracing Tool

MyCi 官方原文 ↗
Cadimage Bracing（支撑/抗侧力）工具仅面向新西兰 ARCHICAD 用户，用于按照 NZS 3604 规范为木框架建筑布置支撑方案。
强烈建议你熟悉 NZS 3604 并手边备有一册以供查阅——除非你已把它背下来了！
设好计算参数后，工具会自动布置支撑线（Bracing Lines）、支撑构件（Bracing Elements）和支撑统计表（Bracing Table）。你仍需添加、编辑、修改正确的数据与对象，确保支撑设计满足新西兰建筑规范和相关标准的全部要求。
Bracing 工具要求墙体使用复合结构（composites）设计，且名称前缀为 EXT（外墙）或 INT（内墙）。
The Cadimage Bracing Tool is an NZ ARCHICAD users only tool that will help you set out your bracing solution for timber-framed buildings under NZS 3604. 
 
It’s highly recommended that you have an understanding of NZS 3604 and have a copy available for reference unless you have memorized it!
 
Once you’ve set your calculation settings the tool with place Bracing Lines, Bracing Elements & a Bracing Table. You will still have to add, edit, modify the correct data & objects to ensure your bracing design meets all of the relevant New Zealand Building Codes and Standards.
 
The Bracing Tool does require wall that is designed using the composites and has the prefix EXT or INT

安装 Cadimage Bracing 工具

Installing the Cadimage Bracing Tool

MyCi 官方原文 ↗

开始之前请确认你已具备：

  • 已安装 ARCHICAD [相应版本]；
  • 已安装 Cadimage Installer，并有 MyCi（https://myci.centralinnovation.com）登录信息；
  • 网络连接；
  • 以电脑管理员（Admin）身份登录。

更详细的安装说明见 第 1 步 - 如何安装 Cadimage 工具

  1. 如 ARCHICAD 正在运行请先关闭。
  2. 打开 Cadimage Installer，为「Commercial/Trial use」选择「Install Cadimage Tools」
  3. 点 My Tools 或 Trial，并选择 ARCHICAD 版本。
  4. 为要安装的 Cadimage 工具点 Install，阅读并接受 EULA（最终用户许可协议）
  5. 装好后关闭 Cadimage Installer 并重启 ARCHICAD。

Before you start please ensure you have:

  • ARCHICAD [Version] Installed,
  • Cadimage Installer Installed & MyCi (https://myci.centralinnovation.com) log in details,
  • Internet Connection,
  • You are logged in as the Admin user of your computer.

 For a more detailed install - Step 1 - How to install The Cadimage Tools

  4. Click Install for the Cadimage Tool you wish to install., read and accept the EULA
  5. Once installed, Close the Cadimage Installer and restart ARCHICAD

设置风区与地震区

Set the Wind & Earthquake Zone…

MyCi 官方原文 ↗

1. 进入要布置支撑的平面视图。从 Cadimage 菜单选择 Bracing > Wind Earthquake Zone。

2. 在弹出的 Wind & Earthquake Zones 窗口中设置 Wind Zone（风区）、Earthquake Zone（地震区）和 Soil Class（场地土类别）。

注意：计算 Wind Zone 有两种方法，用对话框中间的箭头切换。

1. Navigate to the Plan view that you wish to brace. From the Cadimage menu choose Bracing > Wind Earthquake Zone.

2. In Wind & Earthquake Zones pop up window set the Wind Zone, Earthquake Zone & Soil Class.

Note that there are two ways to calculate the Wind Zone, use the arrows in the centre of the dialog to choose one method or the other.

04

单层建筑支撑布置

Bracing a Single Story Building

MyCi 官方原文 ↗

设置风区与地震区…

1. 进入要布置支撑的平面视图。从 Cadimage 菜单选择 Bracing > Wind Earthquake Zone。

2. 在弹出的 Wind & Earthquake Zones 窗口中设置 Wind Zone（风区）、Earthquake Zone（地震区）和 Soil Class（场地土类别）。

注意：

计算 Wind Zone 有两种方法，用对话框中间的箭头切换。

为建筑布置支撑：

3. 进入要布置支撑的平面视图。选中要布置支撑的建筑墙体，从 Cadimage 菜单选择 Bracing > Calculate Bracing。

会弹出 Bracing Settings（支撑设置）对话框。

4. 展开 Calculation Stages（计算阶段）设置，选择 Storey Location 为 single（单层）。

  • 勾选 Place Brace Lines（布置支撑线）和 Place Braces（布置支撑）。

  • 把 Calculation Set（计算集）设为 Default（建筑一次性整体布置时）。如果需要再加第二组支撑、支撑线和表格，每组都要用不同的计算集（见进阶部分）。

注意：

如果需要在项目中任何位置增加第二组支撑、支撑线和表格，每组都要使用不同的计算集（见进阶部分）。

  • 从列表中选择一组 Brace Type（支撑类型）。

5. 展开 Building Dimensions（建筑尺寸）设置，输入建筑的尺寸和屋顶坡度。

设置与建筑长度方向平行的角度。该角度从水平方向起、逆时针计量。示例建筑的角度为零。

6. 展开 Cladding Weights（围护面层重量）设置，为 Roof（屋面）、Upper Cladding（上部围护）和 Subfloor（架空层）选择面层重量。

再选择 Floor Load（楼面荷载）和 Construction Settings（构造设置）。

7. 展开 Brace Settings（支撑设置），设置：

  • 最大支撑长度（Maximum Brace Length）。

  • 最小支撑长度（Minimum Brace Length）。

  • 支撑长度取整（Truncate Braces To）——该设置保证支撑长度取 1.3、1.8 这类规整值，而不是 1.304、1.796。

还要设置支撑的墙龙骨高度，并选择是否允许支撑为适应较矮墙体而降低高度。

8. 最后选择放置全部支撑图元的图层，点 OK。

支撑线会布置到建筑上，支撑会布置在这些线上，以满足 NZS3604 的要求。

9. 接着要指定支撑表的位置，点击放置支撑表。点击处将成为表格左上角。

如果出现问题、所需支撑无法满足，支撑表会如实报告，过程中弹出的提示信息也会说明。

如何添加/编辑支撑，见进阶部分。

Set the Wind & Earthquake Zone…

1. Navigate to the Plan view that you wish to brace. From the Cadimage menu choose Bracing > Wind Earthquake Zone.

2. In Wind & Earthquake Zones pop up window set the Wind Zone, Earthquake Zone & Soil Class.

Note:

There are two ways to calculate the Wind Zone, use the arrows in the centre of the dialog to choose one method or the other.

Brace the building:

3. Navigate to the Plan view that you wish to brace. Select the walls of the building you want to brace, and from the Cadimage menu choose Bracing > Calculate Bracing.

A Bracing Settings dialog will come up.

4. Expand the Calculation Stages settings, and choose the Storey Location, single.

  • Choose to Place Brace Lines and to Place Braces.

  • Set the Calculation Set to Default (if the building is to be braced in one shot). If you need to add a second set of braces, lines and table you’ll need to use a different calculation set for each one. (see advanced section)

Note:

If you need to add a second set of braces, lines and table anywhere in your project you’ll need to use a different calculation set for each one. (see advanced section)

  • Choose a Brace Type Set from the list.

5. Expand the Building Dimensions settings and enter the dimensions and roof pitch of the building.

Set the angle that is parallel with the length of the building. This angle is measured from the horizontal in a counter-clockwise direction. For the example building, the angle is zero.

6. Expand the Cladding Weights settings and choose cladding weights for Roof, Upper Cladding and Subfloor.

Select the Floor Load and Construction Settings.

7. Expand the Brace Settings settings and set:

  • Maximum Brace Length.

  • Minimum Brace Length.

  • Truncate Braces To - this setting ensures that brace lengths will be set to sensible values like 1.3, 1.8 rather than 1.304, 1.796.

Also set the stud height for braces, and choose whether or not braces can be reduced in height for placement on shorter walls.

8. Finally, choose the layer on which to place all the bracing symbols, and hit OK

Brace lines will be placed on the building, braces placed on those lines, so as to satisfy the requirements of NZS3604.

9. You must then indicate the location of the Brace Table, Click to place the brace table. This will be the top left-hand corner.

If there was a problem, and the required bracing could not be achieved, the Brace Table will report this, as will messages that come up throughout the process.

See advanced section on how to add/edit your braces.

Note:

5. In the Calculation Stages settings, and choose the Storey Location. (Lower of two)

  • Choose a Brace Type Set from the list.

Create a Custom Brace Type

MyCi 官方原文 ↗

打开支撑类型管理器（Ci Tools > Bracing > Bracing Types Manager）。

在 Ci Tools Bracing Types 窗口中，选择你常用的支撑集，点 New。

Composite Prefix（复合结构前缀）：INT 仅限内墙，EXT 仅限外墙，INT/EXT 表示内外墙均可使用。

输入描述。

设置长度（务必勾选 Maximum）。

点 OK。

Change the Bracing units to Fixed

团队协作项目中使用 Bracing

Cadimage Bracing in a teamwork project

MyCi 官方原文 ↗

在团队协作（Teamwork）项目中使用 Cadimage Bracing 时，应当：

在布置支撑和计算支撑前，保留（Reserve）所有要参与操作的选中墙体。

在更新支撑时，保留所有已布置的支撑、支撑线和支撑表。

目前预设（Presets）在团队协作中无法正确共享，所以所有支撑预设都应在共享项目之前加载好。

When using Cadimage Bracing in a teamwork project, you should:

Reserve all selected walls you are about to Place Bracing and when Calculating Bracing.


Reserve all placed Braces, Brace Lines and the Brace Tables when you Update Bracing.

Currently Presets are not being shared correctly in Teamwork, so all of your Brace Presets should be loaded before Sharing you project.

疑难：找不到内/外墙（INT/EXT）

Interior/ Exterior Walls Not Found ...

MyCi 官方原文 ↗

如果找不到前缀为 EXT 或 INT 的墙，工具就会停止运行。工具只检查当前选中的墙；若没有选中任何墙，则检查当前楼层所有可见的墙。

If no walls are found with prefix starting with EXT or INT then the tool will stop. Only walls in the current selection are checked; if no walls are selected then all visible walls on the current story are checked.

Archicad 27 版更新：自动尺寸与支撑重新编号

Bracing Updates in Archicad 27

MyCi 官方原文 ↗

建筑尺寸、面积估算与朝向

Bracing 工具新增了尺寸、面积和朝向的自动计算功能。选中全部墙体后，「Calculate Bracing」对话框会自动从所选墙体几何中提取这一估算值。点「Estimate from selected walls」即可填入这些参数。

请注意：面积、宽度和长度是所选墙体外包矩形的近似值，并非建筑的实际尺寸。这些数值应手动调整，以计入挑檐出挑和非矩形区域。

缺陷修复

过去 Bracing 布置时有时不考虑门窗洞口，现已修正——布置支撑时会捕捉全部洞口并相应落位。

界面

界面做了小幅调整，进一步提升了易用性，帮助更深入地理解 Bracing 工具。

Building Dimensions, Floor Area approximation and Orientation

A new feature that has been added to the Bracing Tool is the automatic Dimension, Area and Orientation Calculation. After all walls have been selected, the ‘Calculate Bracing’ Dialogue will automatically extract this approximation from the selected wall geometry. By clicking on ‘Estimate from selected walls’ these parameters will be populated.

Please note that the area, width and length is an approximation of the rectangular shape around the selected walls and not the actual dimensions of the building. These values should be manually adjusted to allow for eaves overhangs and non-rectangular areas.

Bug Fix

In the past Bracing was sometimes placed without consideration of window and door openings, this has been rectified, and all openings are captured during the placement of bracing and bracing placed accordingly.

Interface
