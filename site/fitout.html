Ci Fitout 工具发布

Ci Fitout Tool Released

MyCi 官方原文 ↗

Ci Fitout 工具旨在让你能轻松快捷地完成建筑内各房间的装修配置，无需过多繁琐操作。

只需选择你要装修的房间类型，为其设置一些参数 —— 床的数量、桌子的类型、斗柜或浴缸等 —— 然后在你的房间中点击，即可放置所有元素。

基本上只需一次点击，你就能从空房间变成配置齐全的卧室！

Fitout 工具仅在 Archicad 28 中可用，可通过工具箱中的 Fitout 工具访问（请确保应用 CI Tools 工作环境以使其出现在工具箱中）：

只需选择所需的房间类型，然后在房间中点击进行放置

放置完成后，你可以轻松重新排列已放置的元素，同时仍让它们保持成组，便于整体操作：

你还可以为每个房间中的元素指定各项设置（这些设置也可以保存为收藏，便于你预先备好一批即用型房间预设）

The Ci Fitout tool is designed to allow you to quickly and easily fit out the rooms in your building with a minimum of fuss.

Simply choose the Type of room you are fitting out, set some parameters for it - amount of beds, type of tables, dressers, or baths, etc - and then click on your room to place all the elements.

You can essentially go from an empty room to a fully outfitted bedroom in just 1 click!

The Fitout tool is only available in Archicad 28, and can be accessed via the Fitout tool in your Toolbox (make sure to apply the Ci Tools Work Environment to get it in there):

The just select the Room Type you want, and click in the rooms to place

Once placed, you can easily rearrange the placed elements, while still keeping them grouped together for ease of handling:

And you can also specify the settings for the elements in each room (these can be saved as favourites too, so you can setup a bunch of ready-to-go room presets)

Fitout —— 窗帘处理与门口通行空间

Fitout - Window Treatments and Door Circulation

MyCi 官方原文 ↗

窗帘处理（Window Treatment）

下面我们来看如何创建窗帘处理。

窗帘处理允许在窗户周围定义一个不可占用的空间。我们可以调整 3D 空间，使窗户的上方、下方、左侧和右侧都留有额外净空。

净空的深度也可以定义。

正如上面设置中所看到的，3D 预览会反映出所输入的内容。

窗帘处理既可以用 Fitout 工具自动放置，也可以手动保存为 Set（组合集）。

在保存为 Set 之前，我们也可以在净空空间内放置库对象，如下所示。

这些窗帘处理位于 Fitout 库中。

窗帘处理可以放置在净空区域中，当它被保存为组合集后，将作为一个整体运作，并会根据我们打算用于该 Fitout 的房间/区域（Zone）中所放置的窗户调整宽度和高度。

要将其保存为 Set 以单独使用或在 Fitout 中使用，步骤如下：

  • 放置净空区域和窗帘处理。
  • 在 2D 和 3D 中调整尺寸与位置。
  • 在 2D 或 3D 中选中它
  • 点击 CI Tools > Fitout> Save Objects as a Set（CI Tools > Fitout > 将对象保存为组合集）

我们给它起一个合理的名称，并保存到自选目录。

保存该 Set 后，还可以在随后的对话框中点击 Yes（是），立即用这个 Set 替换已放置的各个独立对象。

如果你希望对该 Set 做更精细的调整，建议保留这些对象，并以相同名称再次保存以替换该 Set。

门口通行空间（Door Circulation）

下面我们来看如何将一个组合集定义为门口通行空间。

门口通行空间允许在门周围定义一个不可占用的空间。我们可以调整 3D 空间，使门的上方、下方、左侧和右侧都留有额外净空。

净空的深度也可以定义。

正如上面设置中所看到的，3D 预览会反映出所输入的内容。

门口通行空间目前只能通过手动保存为 Set 的方式放置。

在保存为 Set 之前，我们也可以在净空空间内放置库对象，如下所示。

门口通行空间的保存方式与上面的窗帘处理完全相同，首先点击 CI Tools > Fitout> Save Objects as a Set（CI Tools > Fitout > 将对象保存为组合集）。

然后选择名称和目录。

现在可以将门口通行空间作为 Set 放置到房间/区域中，从而在门周围形成通行空间。

系统还会提示是否用组合集实时替换这些对象，可以接受或拒绝。

Window Treatment

Let us look at creating a Window Treatment

The Window treatment allows for a space that is off limits to be defined around a window. We can adjust the 3D space to have extra clearance above, below, to the left, and to the right of the window.

The depth of the clearance is also defined.

As can be seen in the Settings above, the 3D preview shows the reflected inputs.

Window treatments can be placed automatically with the Fitout tool, or saved manually as a Set.

We can also place a library object within the Clearance space before saving it as a Set as shown below.

These Window Treatments are in the Fitout Library.

The Window Treatment can be placed in the Clearance Area and when this is saved as a set it will operate as a single entity and adjust the width and height to the Window placed in the Zone we intend to use for the Fitout.

 To save this as a Set, for use on its own, or in a Fitout we proceed as follows:

  • Place the Clearance and Window Treatment.
  • Adjust the sizing and placement in 2D and 3D.
  • Select it in 2D or 3D
  • Click on CI Tools>Fitout>Save Objects as a Set

We give it a sensible name and save it to a directory of our choice.

Upon saving the Set, we can also immediately replace the placed separate Objects with the Set by clicking Yes in the subsequent dialogue.

If you would like to make finer adjustments to the Set, it is advisable to keep the Objects and replace the Set by saving it with the same name.

Door Circulation

Let us look at defining a set as a door circulation

The Door Circulation allows for a space that is off limits to be defined around a door. We can adjust the 3D space to have extra clearance above, below, to the left, and to the right of the door.

The depth of the clearance is also defined.

As can be seen in the Settings above, the 3D preview shows the reflected inputs.

Door Circulation can currently only be placed manually by saving it manually as a Set.

We can also place a library object within the Clearance space before saving it as a Set as shown below.

The Door Circulation is saved as a Set in exactly the same way as a Window Treatment above, First by clicking on CI Tools>Fitout>Save Objects as a Set.

We then choose a name and a Directory.

The Door Circulation can now be placed as a Set in the Zone to create a circulation space around the door.

We are also prompted to replace the Objects with a set in real-time, which we can accept or decline.

如何放置 Fitout

How to Place a Fitout

MyCi 官方原文 ↗

本文将介绍使用 Set 创建的 Fitout 的放置方法。Set 与 Fitout 的创建方式在本节中已有说明。

放置 Fitout 需使用 Fitout 工具 —— 如果工具箱中还没有该工具，可通过加载 Ci Tools Profile 29（CI Tools 配置文件 29）工作环境来添加。

Fitout 示例保存在 CI Tools 库 > Fitout 文件夹中。选择一个示例 Fitout，即可将其放置到房间/区域（Zone）中。

我们以一个浴室 Fitout 为例。在下图所示的房间/区域中，我们将放置一个包含浴缸、淋浴、坐便器（WC）和洗手盆的浴室 Fitout。

在 Fitout 工具中选定要放置的 Fitout 后，即可点击房间/区域内部进行放置。

请注意，Fitout 工具对光标位置十分敏感，它会尝试把优先级较高的对象放置在离你点击光标位置最近的地方。

可能需要多次尝试放置才能得到理想结果。另外值得注意的一点是：如果该房间/区域中尚未放置窗户净空（Window Clearance），Fitout 工具会自动放置一个。

可以看到房间/区域中现已填入一个浴室 Fitout。

如果你对放置结果不完全满意，也可以把其中一个对象移到其他位置。已放置的 Set 会成组，因此请用 Alt+G 或 Command+G 切换 Suspend groups（暂停编组）功能。

我们可以把洗手盆移到更理想的位置，一旦移动，它就会自动吸附到靠近的那面墙。

这就是最终结果。

请参阅知识库中关于编写组合集与装修配置的文章。

This Article will cover the placement of a Fitout created using Sets. The creation of Sets and Fitouts is described in this section.

A Fitout is placed using the Fitout Tool - if you don't already have it in your toolbox, you can add it by loading the Ci Tools Profile 29 work environment.

The Fitout Examples are saved in the CI Tools Library>Fitout Folder. By selecting an Example Fitout, it can be placed in a Zone.

We will use a Bathroom Fitout as an example. In the Zone shown below we will place a Bathroom Fitout that contains a Bath, Shower, WC and hand wash basin.

Once we have selected the Fitout we want to place in the Fitout Tool, we can click in the Zone to place it.

Please note that the Fitout tool is sensitive to cursor placement, and will try to place priority objects closest to where you click the cursor in the zone.

It may be necessary to retry placement more than once to achieve the desired result. It is also worth noting that if a Window Clearance was not placed already in the Zone, the Fitout tool will automatically place one.

We can see that the Zone has now been populated with a Bathroom Fitout.

If you aren't completely satisfied with the placement, you can also move one of the objects into a different position. The placed Sets will be grouped, so Toggle the Suspend groups function with Alt+G or Command+G.

We can move the hand wash basin to a more desirable position, and once we do, it will automatically snap to the wall we move it towards.

This is the result.

Please refer to the Articles about Compiling Sets and Fitouts on the Knowledge Base.

Fitout 简介

Introduction to Fitout

MyCi 官方原文 ↗

本文将介绍如何为你的项目创建量身定制的 Fitout 方案的基础知识。

该方案在重复出现的情形下尤其高效，同时也非常适合同时更改多个空间中的大量项目。

新的 Fitout 功能的工作原理可归纳为三个方面：

对象被放置并转换为 Set（组合集），而放置后的 Set 又被转换为 Fitout（装修配置）。

这些在库中以下列图片表示：

理解新的 Fitout 工具时，最关键的部分是用 Archicad 对象工具放置的全新 Clearance Area（净空区域）对象。

它位于库中 Fitout>Clearances（Fitout > 净空）文件夹下（见下文）：

这让你可以定义对象如何与周边环境交互。

我们共有八个选项可供选择，如下图所示：

这些选项的预期用途如下：

  • Above the Floor Free Standing（独立置于地面之上） —— 例如餐桌组合或沙发
  • Above the Floor against a wall（靠墙置于地面之上）—— 例如电视柜、坐便器（WC）、洗手盆或书架
  • Above the Floor in a Corner（置于转角的地面之上）—— 例如淋浴或落地灯
  • Below Ceiling Free Standing（独立置于吊顶之下）—— 例如吊扇或照明
  • Below Ceiling against a wall（靠墙置于吊顶之下）—— 例如暖通空调机组或重点照明
  • Below Ceiling in a Corner（置于转角的吊顶之下）—— 例如报警探测器或筒灯
  • Door circulation（门口通行空间）—— 放置在门口区域以确保可操作性
  • Window Treatment（窗帘处理）—— 放置在窗户区域以确保可操作性

请参阅关于 Window Treatments（窗帘处理）和 Door Circulation（门口通行空间）净空区域的文章。

In this article we'll look at the basics of creating individually tailored Fitout solutions for your project.

This solution is especially effective where repetition is common, and also very useful to change numerous items simultaneously in several spaces at the same time.

The Basis of how the new Fitout functionality works is threefold:

Objects are placed and converted to Sets, and Sets that are placed and converted into Fitouts.

These are represented in the Library with the following Images:

The most crucial part of the new Fitout tool to understand is the new Clearance Area object that is placed with Archicad’s object tool.

It is located in the Fitout>Clearances folder in the Library(see below):

This allows a definition of how an object will interact with its surroundings.

We have eight options available to select from, as can be seen in the image below:

How these options are intended to be used:

  • Above the Floor Free Standing  - such as a Dining Room Set or a Sofa
  • Above the Floor against a wall -  such as a TV Unit, WC, Basin or a bookshelf
  • Above the Floor in a Corner - such as a shower or a Floor Standing Lamp
  • Below Ceiling Free Standing - such as a Ceiling Fan or Lighting
  • Below Ceiling against a wall  - such as an HVAC unit or feature lighting
  • Below Ceiling in a Corner  - such as an alarm detector or down-lighter
  • Door circulation  - placed in doorway areas to ensure operability
  • Window Treatment -  placed in window areas to ensure operability

Please see the Article on Window Treatmentsand Door Circulation clearances.

ProKit Fitout —— 从这里开始

ProKit Fitout – Start here

MyCi 官方原文 ↗

Fitout（装修配置）工具支持以基于规则的几何方式快速放置家具或任何组件组合。该工具在重复出现的情形下尤其高效，同时也非常适合同时更改多个房间空间中的大量项目。它还包含一套内容广泛且相当精细的组件库，包括：

Bathroom（浴室）

Bedroom（卧室）

Cabinet（橱柜）

Commercial and Domestic Kitchen objects（商用及家用厨房对象）

Dining Room（餐厅）

Healthcare objects（医疗保健对象）

HVAC Equipment（暖通空调设备）

Laundry（洗衣房）

Living Area（起居区）

Office（办公）

Safety and Security equipment（安全与安防设备）。

这些均可通过普通的 ARCHICAD 对象工具访问。

Libpack 加载（自 ARCHICAD 29 起）

请注意，ProKit Fitout 工具需要将 Fitout Libpack 手动加载到项目中。

与所有库一样，这一步通过库管理器（Library Manager）完成。请注意，所加载的 Libpack 需要在单个文件层级上选中，而不像早期 ARCHICAD 版本那样在文件夹层级上选择。

库管理器可通过 File > Library Manager（文件 > 库管理器）下拉菜单访问。

进入库管理器后，我们将使用 "Add"（添加）按钮添加 Fitout Libpack。

这样便可导航到位于 ARCHICAD 安装文件夹中的 ProKit Libpack 文件夹。

这将加载 Fitout Libpack 及其关联的宏。

此时 Fitout 对象即可在对象工具中使用。

重要：

如果两个 Fitout 工具——place Set（放置组合集）和 place Fitout（放置装修配置）以及 Slab（楼板）——没有出现在默认 ARCHICAD 工作环境左侧的工具箱中，可以通过在工具箱上单击右键来添加。工具箱会弹出对话框，可将 Fitout 工具添加进来。

这样便可以把 Coverings（覆盖）工具添加到工具箱中。

Fitout 工具现在会显示出来，建议保存工作环境（Work Environment），以免需要重新添加，尽管 ARCHICAD 应当会保留它们。

放置 Fitout 对象

Fitout 库对象通过 ARCHCAD 中的对象工具放置。

选中该工具后，可以打开设置并放置任意 Fitout 对象。

Fitout 工具支持创建预先保存的房间类型，这被称为一个 Fitout。

Fitout 由 Fitout Set（装修组合集）构成，而后者又由带净空区域的组件（Components）或对象（Objects）组成。通过 ProKit Fitout 下拉菜单将这些内容保存为 Set 和 Fitout。

下图概述了保存 Fitout 的更完整流程。

第一步是用 Archicad 对象工具放置一个 Clearance（净空）对象。

之后便可以在净空区域中放置任意对象。

然后将其保存为一个 Set。做法是选中对象和净空区域，然后将其保存为 Set。通过 ProKit > Fitout > Save Objects as a Set（将对象保存为组合集）执行。

最后，可以放置多个组合集并将其保存为一个 Fitout。

该 Fitout 现在可用于放置在任何 Zone（房间/区域）内。

有关不同 Fitout 功能的更多详细信息，请参阅知识库中的其他文章。

The Fitout Tool allows for very quick placement of furniture or any assembly of components with a rule based geometry method. This Tool is especially effective where repetition is common, and also very useful to change numerous items simultaneously in several zone spaces at the same time. It also contains an extensive sophisticated library of Components consisting of:

Bathroom

Bedroom

Cabinet

Commercial and Domestic Kitchen objects

Dining Room

Healthcare objects

HVAC Equipment

Laundry

Living Area

Office

Safety and Security equipment.

These are accessible through the normal ARCHICAD Object Tool.

Libpack loading (since ARCHICAD 29)

It is important to note that the ProKit Fitout Tool requires the Fitout Libpack to be manually loaded into the project.

As with all Libraries this is done through the Library Manager. Please note that the Libpacks that are loaded need to be selected at an individual file and not at a folder level as was the case in earlier ARCHICAD versions.

The Library Manager is accessed through the File>Library Manager dropdown.

Once in the Library Manager we will use the “Add” button to add the Fitout Libpack.

This allows navigation to the ProKit Libpack folder located in the ARCHICAD installation folder.

This will load the Fitout Libpack and associated Macros.

The Fitout Objects will now be available in the Object Tool.

IMPORTANT:

If the two Fitout Tools, place Set and place Fitout, and Slab are not showing in the toolbox on the left in the default ARCHICAD work environment, they can be added by right clicking on in the Toolbox. The Toolbox will bring up a dialog to add the Fitout Tools.

This will allow adding the Coverings Tools to the Toolbox.

The Fitout Tools will now show up, it is recommended to save the Work Environment to avoid having to add this, although ARCHICAD should retain them.

Placing a Fitout Object

The Fitout library objects are placed with the Object Tool in ARCHCAD.

Once the tool is selected, the settings can be opened and any Fitout Object placed.

The Fitout Tool allows for the creation of a pre-saved room type, this is referred to as a Fitout.

The Fitout is comprised from a Fitout Set, which in turn is made up of Components or Objects with clearance areas. These are saved as a Set and a Fitout using the ProKit Fitout dropdown.

The Diagram below outlines the broader process of saving a Fitout.

The First step is to place a Clearance object with the Archicad Object Tool.

After this any objects can be placed in the Clearance Area.

This is then saved as a Set. We do this by Selecting the Object and Clearance, and saving it as a Set. This is done through ProKit>Fitout>Save Objects as a Set.

Lastly, multiple sets can be placed and saved as a Fitout.

This Fitout is now available for placement inside any Zone

For more detailed information on the different Fitout features please see the other articles on the Knowledge-base

Bedroom

Cabinet

Commercial and Domestic Kitchen objects

Dining Room

Healthcare objects

HVAC Equipment

Laundry

Living Area

Office

Safety and Security equipment.
